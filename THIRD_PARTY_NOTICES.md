# Third-party notices

RegexMate builds on the components below. Each entry names where the
component enters the shipped artifacts and the license it is distributed
under; consult the upstream license files for full terms. The Rivet
toolchain is a first-party TurLamAI project (MIT) consumed as a pinned
package — not third-party code — so it is not listed here. This file is
the authoritative grouping overview; every release additionally ships a
per-asset `THIRD_PARTY_NOTICES.txt` (generated by the Rivet toolchain)
inside the release payload.

## Racket CS runtime

The CLI embeds the Racket CS runtime (`raco exe` + `raco distribute`;
[racket/racket](https://github.com/racket/racket), 9.x) and the GUI
statically links it via Rivet's embeddable build. Racket is distributed
under the MIT license and the Apache License 2.0, at your option; the
Racket CS runtime system additionally embeds Chez Scheme, distributed
under the Apache License 2.0 (per Racket's `LICENSE.txt`).

## pict

The railroad diagrams (`regexmate graph`) render with the `pict`
library, part of the Racket distribution and embedded alongside the
runtime above. `pict` is distributed under the MIT license and the
Apache License 2.0, at your option.

## GTK 4 and GLib

The Linux GUI host is a GTK 4 application. GTK and GLib are licensed
under the GNU Lesser General Public License, version 2.1 or later.
They are not bundled: deb / rpm / AppImage / tar.gz shapes take GTK 4
and its system libraries from the distribution as runtime dependencies.

## Windows App SDK (WinUI 3)

The Windows GUI host is a C++/WinRT WinUI 3 application built against
[Microsoft Windows App SDK](https://github.com/microsoft/WindowsAppSDK)
(`Microsoft.WindowsAppSDK`); the self-contained build ships its UI
runtime DLLs inside the package. The Windows App SDK is licensed under
the MIT license. The C++/WinRT language projection used at build time
is also MIT.

## AppImageKit runtime (`.AppImage` artifacts)

`.AppImage` release artifacts contain the type-2 AppImage runtime from
[AppImage/AppImageKit](https://github.com/AppImage/AppImageKit),
licensed MIT. AppImageKit's license does not apply to the contents of
the AppImage: those are RegexMate's payload plus the entries above.
